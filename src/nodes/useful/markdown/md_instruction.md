# 6. 链接
    1. 网址链接
    [方括号里放显示的文字](圆括号里放网址)

    示例：
    [百度](https://www.baidu.com "点击进入百度首页")

    2. 图片链接
    ![图片替代文字](图片地址.png)

    3. 如果网址太长，写在文本中不好看，可以用定义的方式（通常放在文尾）

    [百度]: https://www.baidu.com

    [谷歌]: https://www.google.com "谷歌搜索"

    调用时：
    [百度][]

    4. 文件链接
    [文件名](文件路径)
    
    5. 具体代码链接
